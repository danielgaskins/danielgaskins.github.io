TIER 1: DENSE LATCH (< 100 KB)

Selected automatically when linear separability holds (Qwen2.5-7B, Gemma-2-9B). Compiles standardized detection weights alongside manifold-aligned planning-block steering vectors (0.999985 cosine parity with closed-loop Paper 1 breakers) so low-variance residual channels are never amplified.

TIER 2: 16K JUMPRELU + ANCHOR LATCH

Selected when superposition collapses dense probes (Gemma-2-2B, LTX-Video-0.9.5, Cosmos-Predict2.5, Cosmos-Policy). Applies token-first sparse encoding before spatial-temporal pooling and penalizes norm-matched confounders via TopK(d_bad - λ d_confound).

When a frozen open-weights SAE already exists (such as Gemma Scope params.npz or a shared Cosmos backbone checkpoint), passing --base-sae skips dictionary pretraining altogether and calibrates task-specific diagnostic latents and conformal thresholds in under 10 seconds. When training a new 16,384-latent JumpReLU dictionary from scratch via latchgate train-sae, the trainer incorporates activation replay buffering (Koriagin et al., 2026) to prevent temporal correlation collapse on sequential video tokens and optional channel-weighted reconstruction (--wsae-weights) for heavy-tailed world-model channels.

QUICKSTART A / AGENTS (TRANSFORMERS · VLLM · SGLANG)

Catch Silent Commitment ~30 tokens before TOOL_CALL:

Monitors the token-28 <think> checkpoint and the pre-tool boundary in under 1 ms. On benign coding prompts the hook stays dormant (0.0% false triggers); when shortcut commitment crosses τ, it aborts or latches 4-layer manifold steering across TOOL_CALL: to defeat Action Re-Locking. 

from latchgate import LatchGate, TransformersLatchHook

gate = LatchGate.from_pretrained("qwen2.5-7b-sabotage")
with TransformersLatchHook(
    model, tokenizer, gate, mode="latched_steer"
) as hook:
    out = model.generate(**inputs, max_new_tokens=256)
print(hook.events)

04 / CI-TO-RUNTIME LOOP

Mendmark finds silent trace blind spots in CI. LatchGate blocks them in the residual stream.

Curating paired counterfactual trajectories by hand is the main bottleneck when deploying activation gates on proprietary tool schemas. Starting in Mendmark v0.7.2, mendmark export-latchgate converts clean passing agent cases and planted trace mutations (or strictly the evaluator-evading survivors via --survivors-from audit.json) directly into latchgate.pair.v1 JSONL training pairs for latchgate fit.

What ships in v0.1.0

  • Adaptive latchgate fit compiler (dense_latch + sae_anchor_latch)
  • Fast < 10 s frozen --base-sae task calibration (.safetensors, Gemma Scope .npz, .lgate)
  • Replay-buffered latchgate train-sae with optional WSAE channel weighting
  • TransformersLatchHook, VLLMLatchEngine, and SGLangLatchHook
  • CosmosLatchFirewall, DiffusersLatchCallback, and shield_value_critic
  • Direct mendmark export-latchgate JSONL ingestion

Deployment boundaries

  • Requires white-box residual-stream access on self-hosted open-weights models; closed API wrappers without hidden-state hooks cannot run in-stream gates
  • Conformal 0.0% benign false-trigger thresholds hold on the calibrated prompt or task distribution and should be re-verified when policies or tool schemas shift
  • In 3D DiTs and embodied world models, zero-decode early abort rejects corrupted seeds or action candidates rather than rewriting an invalid robot action in flight
  • In-stream circuit breakers complement external permission sandboxes, deterministic CI mutation audits (Mendmark), and human review
